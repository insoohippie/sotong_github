# 5.6일 패딩 작업 — 설명서

## 목적

- **가로**: 화면 너비에 비례하는 좌우 여백을 한 곳에서 계산하고, 뷰에서는 **비율(또는 상수)** 만 넘긴다.
- **세로**: 구역(블록) **사이** 간격만, **기준 높이 600**을 기준으로 스케일하고, 각 뷰에서는 **숫자 리스트 (a,b,…)** 만 정의한다.
- 클래스·파일명으로 **가로 / 세로**를 구분하기 쉽게 정리했다.

---

## 규칙 파일 (2개)

| 파일 | 역할 |
|------|------|
| `lib/component/theme/padding/horizontal_padding_clamped_fraction.dart` | **가로** 패딩. `width × widthFraction` 후 **16~40 pt** 로 클램프. 클래스: `PaddingResponsive16_40Vw` |
| `lib/component/theme/padding/vertical_section_spacing_ref_height_600.dart` | **세로** 구역 간 간격만. 뷰 높이 600 미만·이에서는 스케일 1, 초과 시 `h/600` 배. 클래스: `SectionGapRefHeight600` |

### 가로 사용 예

```dart
import 'package:sotong_local/component/theme/padding/horizontal_padding_clamped_fraction.dart';

// 비율 직접 전달 또는 클래스 상수 사용
PaddingResponsive16_40Vw.horizontal(context, PaddingResponsive16_40Vw.fractionModal06);      // 플랜 입력 모달 등
PaddingResponsive16_40Vw.horizontal(context, PaddingResponsive16_40Vw.fractionScreen075); // 일반 화면·auth 등
```

- `symmetric(..., widthFraction:, vertical:)` 로 좌우 클램프 + **세로 고정 px**를 같이 줄 수 있다. (**세로 구간 스케일**과는 별개.)

### 세로 사용 예

```dart
const _mins = [12.0, 24.0]; // 맨위~1, 1~2 … (버튼은 목록에서 제외한 구성 많음)
final gaps = SectionGapRefHeight600.scaledMinsFromContext(context, minGaps: _mins);
SizedBox(height: gaps[0]);
```

- 최소 pt `(a,b,…)` 는 **이 파일 안에 두지 않고**, 각 화면 상단 등에서 `const` 리스트로만 둔다.

## ViewModel

- 패딩 유틸을 **직접 import 하는 ViewModel은 없음.** 레이아웃은 Widget 쪽 책임.

---

## 히스토리 (이름 변경·통합)

1. 예전에는 가로만 `padding_responsive_16_40_0_06vw.dart` / `…0_075vw.dart` 두 파일이 있었음 → **비율을 인자로 받는 하나**로 합치고 현재 파일명으로 정리함.
2. 세로 규칙은 `section_gap_ref_height_600.dart` 등으로 가다가, **현재 이름**인 `vertical_section_spacing_ref_height_600.dart` 로 통일.
3. 패딩 폴더에 **파일 이름만 봐도 가로 vs 세로**가 드러나도록 함.

(삭제·대체된 예전 파일명은 `docs/5.6일, 패딩작업.txt` 하단 참고.)
